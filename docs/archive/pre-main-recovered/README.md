# Historical branch evidence recovered for pre-main

These byte-identical originals preserve work from branches that were absent from the current file tree. They are historical documents for their recorded source commits, not current code, provider prices, owner approval, release-gate results or performance measurements. Current facts live in docs/execution/PRE_MAIN_PHASE_4_5.md and its verification/gate evidence.

manifest.json records each source ref/commit, original path, archive path, byte length and SHA-256. Obsolete application implementations and old synthetic datasets are preserved through Git history rather than restored over the current reviewed implementation. The archived check-local.sql is a historical source artifact and is not executed by the active tooling.
