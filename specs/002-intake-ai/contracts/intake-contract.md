# Feature 002 interface contract plan

This is a specification for future validated route DTOs. docs/code/fera_types_v2.ts and D2 Part A §5.5 are authoritative; src/contracts/ does not yet exist. Route order is Zod input → role guard → per-role DTO allowlist → error envelope, with same-origin checks on state-changing requests. No raw row, child text in logs or other-party payload is returned. (BR-007/024; NFR-010; TC-019/060)

| Interface | Request and validation | Success and recovery |
|---|---|---|
| API-001 POST /api/intake/transcribe | Multipart synthetic audio, kind, optional draft token; optional protected-DEMO fixture ID. Notice precedes dispatch. Verify codec, encoded size ≤2 MB, measured duration 5–120 s, owner/expiry and atomic paid reservation. (FR-002; BR-004/023; TC-061) | TranscribeResponse: editable transcript, verified duration, language hint, cached flag, opaque draft ID/token, server-owned calls used. E-007–E-011/E-014/E-015/E-023 surface typed/manual fallback; no silent cache. (COMP-006/017; TC-001/021) |
| API-002 POST /api/intake/extract | Synthetic kind, text or answer, prior CaseDraft and token when continuing. Typed input 20–2,000 characters; validate source spans, district/required fields, revision/owner/expiry, four rounds and six dispatched paid calls. (FR-001/003–005; BR-008/015/023; TC-002/003/043) | ExtractResponse: device-held editable draft, evidence, explicit missing fields, one next question or null, draft ID/revision/token/expiry, calls used and cached flag. Two invalid outputs, provider down, rate/budget refusal or exhausted rounds preserve known values for SCREEN-005. (COMP-007–009; FR-026; E-001/012/013/019/023) |
| API-003 POST /api/cases | CreateMissingRequest: reviewed missing CaseDraft, confirmed=true, client submission UUID, optional token. Validate BR-015/016, synthetic-only mode, own principal, canonical payload hash and same-origin JSON. (FR-006/007/031; TC-004/030/060) | 201 new OwnerCaseView; 200 identical UUID+hash retry with stable reference and replayed=true; changed payload E-005. Return explicit matching state and output availability. Persist via case service, audit and owner DTO only; failed matching has queued/failed state, never an unawaited promise. (BR-004/024; TC-031/042/054) |

**Provider interfaces**: SpeechProvider.transcribe(audio,mime,bn) yields text and verified duration; LLMProvider.extractCase(ExtractInput) yields ExtractOutput only after Zod, evidence and source-span checks. Preserve raw-to-normalised offsets. Record model ID, prompt version, latency and cost metadata per paid call without source text, transcript or phone. Provider accounts/prices are UNKNOWN. (COMP-006–008; BR-008/023; TASK-003/013/014; OQ-004/022)

**Error envelope and role projection**: consume feature 001's frozen DTO/error contract when available; this document does not redefine E-001–E-024. Parent only sees own draft/report status. Unverified or foreign access uses the specified envelope and audit path; API-003 idempotency key is principal-scoped. (BR-007/024; TC-019/022/031/042; TASK-061)
